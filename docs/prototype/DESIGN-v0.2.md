# 마리오네트 신디케이트 (Marionette Syndicate)

> 중세 궁정 암투 테마의 1대1 심리전 보드게임. 10×10 보드, 3판 2선승.
> Steam 출시 목표. 의존성 없는 단일 HTML로 프로토타입 → 추후 Electron 래핑.

---

## 1. 핵심 콘셉트
- **테마**: 중세 궁정 암투
- **장르**: 10×10 보드 위 1v1 심리전
- **방식**: 3판 2선승제
- **시그니처**: HP 개념 없음. **단 한 번의 공격으로 즉시 처형(사망)**. → 극단적 긴장감.

## 2. 용어 (★ 확인 필요)
- **매치**: 3판 2선승 한 세트.
- **판(게임)**: 보드 1회 대결. 판 시작마다 지령(VIP/타겟) 새로 배정.
- **턴**: 한 플레이어의 행동 차례. **턴마다 AP 3 지급** (사용 못 한 AP는 소멸).

## 3. 게임 규칙
### 지령 시스템 (심리전의 심장, 상대에게 비공개)
- 판 시작 시 무작위 배정:
  - **VIP**: 내 기물 중 하나 — 죽으면 **즉시 패배**.
  - **타겟**: 상대 기물 중 하나 — 내가 처형하면 **즉시 승리**.
- 서로 상대의 VIP/타겟을 모름 → 움직임으로 역추리하는 게 핵심.

### 진영 / 매수
- 시작 시 진영(청/적) 구분.
- **3턴 경과 후**부터 상대 진영 기물 **매수** 가능 (루렌 소모, 내 편으로 전환).

### 행동력(AP) — 턴마다 3
- **채광**: 1 AP → 루렌 +2
- **이동**: 1 AP → 기물 고유 이동 거리만큼
- **처형(공격)**: 1 AP → 사거리 내 적 기물 즉시 사망
- **카드 사용**: 손패 5장 중 선택 (코스트는 카드별)
- **특수 능력**: 기물별 (예: 군주 '왕가의 지휘' 2 AP)

### 승패 — 이중 조건 (확정)
- **판 승리**: ① 내 타겟 처형 **AND** ② 상대 VIP 제거, 둘 다 달성 시 즉시 승.
- 두 대상 모두 적 기물이라 둘 다 내 손으로만 죽일 수 있음. 둘이 같은 기물이면 한 방에 충족.
- VIP는 죽는 순간 정체 공개(죽음 공개) → 이중 조건 추적 가능.
- 매치: 2판 먼저 이기면 승.

### 경제 — 농노/루렌 (확정)
- **농노**: 기물이자 경제 기반. 진영당 4명, 1행/8행 배치. 이동 1칸·공격 불가.
- **수입**: 턴 시작 시 자동 +루렌 = (살아있는 내 농노 수)×2.
- 루렌 용도: 매수, 카드.

### 매수 — 충성도 전쟁 (확정)
- **4턴째부터** 활성화.
- 내 기물에 인접(1칸)한 적을 루렌으로 전향. 1 AP 소모.
- 비용(★튜닝): 농노 3 / 일반 궁정 6 / 군주 매수 불가 / 첩자가 매수하면 −3(최소 2).

## 4. 기물 로스터
> moveRange = 이동 칸수, execRange = 처형 사거리(0=공격불가). ★ 군주만 확정, 나머지는 제안.

| 기물 | 이동 | 처형거리 | 특수 |
|------|------|----------|------|
| 군주 (Lord) | 전 방향 1칸 | 1 | ★확정. 2 AP '왕가의 지휘': 주변 8칸 적 이동불가 + 인접 성기사 강화 |
| 성기사 (Paladin) | 직선 2칸 | 1 | 강화 시 처형거리 +1 |
| 자객 (Assassin) | 대각 3칸 | 2 | 암살 특화, 방어 약함 |
| 첩자 (Spy) | 전 방향 2칸 | 1 | 매수 코스트 감소 / 정보 |
| 궁수 (Archer) | 직선 1칸 | 3 | 원거리 처형 |
| 사제 (Priest) | 전 방향 1칸 | 0 | 인접 아군 1회 보호(처형 무효) |

## 5. 로드맵

- **v0.2**: 매수 + 루렌 경제 + 군주 특수.
- **v0.3**: 카드 5종 시스템.

## 6. 기술
- 단일 HTML + 바닐라 JS (의존성 0). 기물은 데이터 주도(config) → 숫자 튜닝 용이.
- 추후 Electron으로 스팀 배포.
