# Force Chamber · 힘의 격실

힘과 기하로 여는 물리 방탈출 퍼즐. 무인 역학 실험동의 격실 문은 열쇠가 아니라 물리 법칙으로 열립니다.
이 실험동의 중력은 지구와 다르고(실험마다 무작위), 마찰계수·질량·줄의 강도 같은 미지수도 매번 새로 정해집니다.
답을 외울 수 없고, 직접 재고 계산해야 합니다.

## 챕터 1 · 보정 구역 (현재 공개)

| 격실 | 이름 | 방식 | 자물쇠 |
|---|---|---|---|
| 01 | 자유낙하 | 조작 · 계산 | **A** 광문 시간으로 이 실험동의 g 측정 · **B** 정해진 시각에 충돌판을 때리도록 낙하 높이 설정 |
| 02 | 경사면 | 조작 · 계산 | **A** 미끄러지기 시작하는 각도로 μs 측정 · **B** 밀어 준 블록이 등속으로 내려가는 각도(tan θ = μk) 찾기 |
| 03 | 두 줄 | 조립 · 계산 | **A** 두 줄과 고리 위치를 골라 매듭을 표적에 정지 (한계 장력 넘으면 끊어짐) · **B** 라미의 정리로 왼쪽 줄 장력 계산 |

격실 04–14(지렛대, 무게중심, 도르래, 용수철, 포물선, 공기 테이블, 구르는 원통, 진자, 부력, 중력 벡터, 마지막 문)는
격실 목록에 "준비 중"으로 표시됩니다.

## 실행

빌드 없이 `index.html`을 브라우저로 열면 됩니다. 로컬 서버가 편하다면:

```sh
npm start          # http://localhost:3000
npm run build      # dist/force-chamber.html — 파일 하나짜리 배포본
npm test           # 물리 엔진 정확도 + 격실 풀이 가능성 테스트
```

## 조작

| 키 | 기능 |
|---|---|
| `H` | 손: 장치 조작 (주황색이 조작 가능한 부분) |
| `M` | 자: 두 점 사이 거리·각도 측정, 꼭짓점·광문·표적에 달라붙음 (`Shift`: 5 cm 격자) |
| `F` | 힘 벡터 (중력·수직항력·마찰력·장력·탄성력·부력) |
| `T` | 스트로보 잔상 (1/20 s 간격) |
| `Space` / `.` | 일시정지 / 한 칸 진행 |
| `R` | 격실 초기화 (연 자물쇠는 유지) |
| `Esc` | 측정선 지우기 |

코드 자물쇠는 세 번 틀리면 20초 잠깁니다. 힌트를 볼 때마다 그 격실의 별점이 하나 줄어듭니다.

## 구조

```
src/core      벡터·변환·난수, 계산 기하 (다각형 질량, 반평면 클리핑, 원의 교점, 벨트 접선)
src/physics   강체 엔진: SAT 충돌 + 기준면 클리핑, 분할 임펄스 순차 솔버, 정지/운동 마찰,
              반발계수, 핀·막대·로프·도르래 로프·슬라이더 조인트, 용수철, 부력
src/game      격실 런타임(자물쇠·조작·타이머·기록), 광문·센서 장치, 진행 저장
src/render    방안지 위 기술 도면 스타일 렌더러 (해칭, 치수선, 계기 표시)
src/ui        조작 패널, 도구, 모달, 효과음
src/rooms     격실 정의 (c01–c03), 로드맵
tests         엔진 정확도 테스트, 격실별 헤드리스 풀이 테스트
tools         단일 파일 빌드
```

엔진은 해석해와 비교해 검증합니다: 자유낙하·포물선(정확), 정지마찰 문턱각, 운동마찰 가속도,
반발 높이 e²h, 진자 주기, 애트우드 기계, 움직도르래 2:1, 구름 운동 a = g sinθ/(1+β), 부력 흘수,
탄성 충돌 90° 분리, 쿠션 반사, 지렛대 평형, 훅의 법칙.
격실 테스트는 숨은 정답을 읽지 않고 플레이어처럼 측정→계산→조작하는 경로로 여러 무작위 실험동에서 풀어 봅니다.
