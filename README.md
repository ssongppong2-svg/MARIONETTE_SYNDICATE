# Nudge

주인공은 마우스 포인터입니다. 몸이 있어서 벽에 막히고, 힘은 **40 N**밖에 없습니다.
분홍 벽 너머의 빛에 닿아야 하는데, 벽은 **620 N**을 2.5초 넘게 받아야 무너집니다.

중학교 1학년 2학기 「힘」 단원(힘의 표현, 중력과 무게, 탄성력, 마찰력, 부력, 합력과 평형)만으로
만든 초고난도 방 하나입니다. 파스텔 톤에 말랑한 움직임과 흐르는 물을 담았고, 화면 안에는 글자가 없습니다.

## 실행

`index.html`을 브라우저로 열면 바로 시작합니다.

```sh
npm start        # 로컬 서버
npm run build    # dist/nudge.html — 파일 하나짜리 배포본
npm test         # 엔진 정확도 + 퍼즐 메커니즘 + 포인터만으로 끝까지 푸는 시뮬레이션
```

## 조작

| | |
|---|---|
| 움직이기 | 마우스를 움직이면 포인터가 따라갑니다. 막히면 실제 마우스 위치가 점선 유령 커서로 보입니다 |
| 밀기 | 물체 쪽으로 마우스를 더 깊이 밀어 넣을수록 세게 밉니다 (최대 40 N) |
| 처음부터 | `R`, 또는 버튼을 누른 채 1.6초 가만히 있기 |
| 터치 | 끌어서 움직입니다. 손가락에 가리지 않도록 포인터는 손끝보다 조금 위를 향합니다 |

## 설계 메모 (스포일러)

<details>
<summary>퍼즐 구조와 숫자</summary>

- **합력:** 램은 마찰 없는 레일 위에서 두 줄에 끌려 벽을 밉니다.
  - 줄 1은 우물 속 양동이에 걸려 있어 *양동이의 무게 − 부력*으로 당깁니다.
  - 줄 2는 우물 바닥의 도르래를 돌아 부표에 이어져 있어, 부표가 물에 잠겼을 때만 *부력 − 무게*로 당깁니다.
  - 램의 흰 화살표 길이가 지금 벽을 미는 힘입니다(힘의 표현).
  - 벽은 받는 힘에 비례해 휘다가(탄성력) 한계를 넘으면 금이 갑니다.
- **마찰력:** 돌(10 kg, 밀도 1667)은 거친 바닥에 놓여 있습니다.
  - 마른 상태에서는 최대 정지마찰력이 0.7 × 98 N ≈ 69 N이라 포인터로는 밀 수 없습니다.
  - 물에 잠기면 부력이 누르는 힘을 줄여 ≈ 27 N이 되고, 그제야 밀립니다. 끝의 얼음판을 지나 양동이로 떨어집니다.
  - 가벼운 부석은 마른 채로도 밀리지만, 물에서는 떠 버립니다.
- **물:** 위 저수조의 판(유입 2.4 m²/s)과 우물 바닥의 마개(배수 1.6 m²/s)는 포인터로 밀어서 엽니다.
  유입이 배수보다 빠르므로, 물을 빼려면 판부터 닫아야 합니다.
- **수위별 벽이 받는 힘** (돌 4개를 실었을 때):

  | 상태 | 벽이 받는 힘 | 결과 |
  |---|---|---|
  | 가득 찼을 때 | 약 450 N | 양동이가 잠겨 가벼워짐 |
  | 다 뺐을 때 | 약 480 N | 부표가 물 밖이라 줄 2가 느슨함 |
  | 양동이는 물 밖, 부표는 물속 (수위 약 −0.1 ~ 0.85 m) | 약 745 N | 무너짐 |

  이 구간에서 마개를 닫아 수위를 붙잡아야 합니다. 그냥 흘려보내면 너무 빨리 지나가 벽이 버팁니다.
</details>
