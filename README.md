# Fragment

검은 세계 속에 흰 파편이 하나 있다. 글자도, 버튼도, 힌트도 없다. 힘으로만 닿을 수 있다.

중학교 1학년 과학 「힘」 단원(힘의 표현, 중력과 무게, 탄성력, 마찰력, 부력, 힘의 평형)을 재료로,
교과서보다 한 단계 깊이 들어간 물리 퍼즐 데모입니다. 파편은 하나, 퍼즐은 여러 힘이 얽힌 한 덩어리입니다.

## 실행

`index.html`을 브라우저로 열면 바로 검은 화면에서 시작합니다.

```sh
npm start        # 로컬 서버
npm run build    # dist/fragment.html — 파일 하나짜리 배포본
npm test         # 엔진 정확도 + 퍼즐 메커니즘 + 전체 풀이 시뮬레이션
```

## 조작 (게임 안에는 어떤 안내도 없다)

| | 키보드 | 마우스·터치 |
|---|---|---|
| 걷기 | ← → / A D | 빈 곳을 누르고 있으면 그쪽으로 걷는다 |
| 점프 | ↑ / W / Space | 점 위쪽을 짧게 톡 |
| 물체 끌기 | — | 빛이 닿는 물체를 눌러 끈다 (힘의 화살표가 보인다) |
| 처음부터 | R | 점을 1.4초 누르고 있기 |

## 설계 메모 (스포일러)

<details>
<summary>퍼즐 구조</summary>

- 파편은 깊은 우물 바닥, 물에 잠긴 방 안에 갇혀 있다. 문은 용수철이 받치는 바닥판에 붙은 판이고,
  판의 구멍은 바닥판이 **0.42–0.68 m** 내려갔을 때만 방 입구와 맞는다. 평소에는 가는 틈으로 빛만 샌다.
- 바닥판이 내려가는 깊이 = (짐의 무게 − 부력) ÷ 용수철 상수. 물속에서 중요한 것은 무게가 아니라 **밀도**다.
- 연못 바닥의 큰 돌(밀도 1.9): 땅에서는 손 힘(300 N)보다 무거워 못 들지만, 물속에서는 가벼워져 들린다.
  매끈한 경사로를 따라 끌어올릴 수 있다. 하지만 우물에 넣으면 물속 무게가 모자라 0.29 m만 내려간다.
- 거친 땅 위의 작은 납덩이(밀도 11.3): 들 수도, 똑바로 끌 수도 없다(최대 정지마찰력 = μ × 누르는 힘 > 손 힘).
  비스듬히 위로 당기면 누르는 힘(수직항력)이 줄어 미끄러진다. 우물에 넣으면 정확히 0.55 m.
- 둘 다 넣으면 0.84 m로 지나쳐 문이 다시 닫힌다. 되돌릴 수 없으면 세계가 조용히 처음으로 돌아간다.
- 풀려난 파편은 물보다 가벼워 기울어진 천장을 타고 빠져나와 떠오른다.
</details>

## 구조

```
src/core       벡터·변환·난수, 계산 기하
src/physics    강체 엔진: SAT 충돌, 분할 임펄스 솔버, 정지/운동 마찰, 반발, 조인트, 용수철, 부력
src/fragment   level(세계) · actors(점과 손) · rules(규칙) · light(가시 다각형 조명)
               view(그리기) · input · audio · main
tests          엔진 정확도 테스트, 퍼즐 메커니즘과 전체 풀이 테스트
tools          단일 파일 빌드
```
