# ΣF

마우스가 **견인줄**입니다. 용수철처럼 늘어날수록 세게 당기지만(F = kx, k = 600 N/m), **360 N**을 넘지 못합니다.
방 안의 모든 물체와 장치가 질량·무게·마찰력·부력·탄성력·장력을 실시간으로 쏟아냅니다.
그 숫자들로 계산하고 정확히 조작해서 금고문을 열고, 안의 코어 **C-0**을 꺼내면 끝입니다.

중학교 1학년 2학기 「힘」 단원(힘의 표현, 중력과 무게, 탄성력, 마찰력, 부력, 합력과 평형)만으로 만든
초고난도 방 하나입니다. 어두운 관제 화면 위에 벡터 HUD, LED 계기판, CRT 오실로스코프를 섞었습니다.

## 실행

`index.html`을 브라우저로 열면 바로 시작합니다.

```sh
npm start        # 로컬 서버
npm run build    # dist/sigma.html — 파일 하나짜리 배포본
npm test         # 엔진 정확도 + 장치 메커니즘 + 견인줄만으로 끝까지 푸는 시뮬레이션
```

## 설계 메모 (스포일러)

<details>
<summary>장치와 숫자</summary>

- **유리 GL-A**
  - 주 밸브 V-1이 든 캐비닛을 막고 있습니다.
  - 충격력 F ≈ Δp/Δt(Δt = 0.05 s 가정)가 **900 N** 이상이어야 깨집니다.
  - 가만히 밀어서는 깨지지 않고, 돌을 던져야 합니다.
- **침수 구역 S와 뗏목 RF-1**
  - 바닥에 놓인 화물 상자 K-64(627.2 N)는 들 수 없습니다.
  - 물을 채우면 뗏목이 떠올라 상자를 갑판 높이로 올려 줍니다.
  - 뗏목 상면 = 수위 + 건현이고, 수위 **약 2.38–2.50 m** 구간에서 상자를 옮길 수 있습니다.
  - 2.50 m를 넘으면 물이 넘쳐 평형추 버킷으로 흘러 들어가고, 무게 계산이 어긋납니다.
- **거친 갑판**(μs 0.62, μk 0.48)
  - 수평으로 당기면 F_N = 627.2 N이고, f_s,max = 388.9 N > 360 N이라 꿈쩍하지 않습니다.
  - 비스듬히 위로 당기면 수직항력이 줄어 미끄러집니다.
- **해치 H-1과 트랩 레버 T-1**
  - 해치는 그 위의 무게를 재는 하중 셀입니다.
  - 레버는 용수철 걸쇠(F = 150 N + 500 N/m · x)이며, x ≥ 0.25 m에서 해치가 열립니다.
- **평형추 버킷 CW와 금고문 D-1**
  - 문 m_D = 120 kg이고, 가이드 마찰은 f_s 54 N, f_k 36 N입니다.
  - 조속기는 0.60 m/s에서 작동하고, 넘으면 LOCKOUT입니다.
  - 출발 조건은 W_CW > W_D + f_s입니다.
  - 운동 중에는 W_CW − W_D − f_k = (m_D + m_CW)·a, v_top = √(2·a·1.2 m)입니다.
  - 따라서 버킷 적재물(버킷 18 kg 제외)은 **약 107.5–109.4 kg**이어야 합니다.
  - 상자 64 kg에 나머지 43.5–45.4 kg을 돌과 물로 맞춥니다. 니들 밸브 V-2(최대 1.5 kg/s)로 미세 조정할 수 있습니다.
- **해제 핀**: 버킷을 받치던 거치대를 빼서 한 번에 결과를 확정합니다.

**검증된 풀이 예시**

1. S-8(29.8 kg)과 S-4(13.9 kg)를 해치에서 계량한 뒤 떨어뜨립니다.
2. 갑판 위 장애물을 치웁니다.
3. 돌을 던져 유리를 깹니다.
4. 밸브를 열고, 수위 약 2.43 m에서 닫습니다.
5. 상자를 비스듬히 끌어 해치로 옮겨 떨어뜨립니다.
6. 니들 밸브로 물 약 0.9 kg을 더합니다.
7. 핀을 뽑습니다. 문이 v_top ≈ 0.52 m/s로 열립니다.
8. 코어를 꺼냅니다.
