# Nudge 태초의 문

너는 마우스 포인터다. 미는 힘은 **40 N**, 붙잡아 끄는 줄은 **60 N**이 전부이고, **60 N**이 넘는 충격을 받으면 산산이 부서진다.
태초의 문을 연 열쇠는 여섯 조각으로 쪼개져 세계 곳곳에 숨겨져 있다. 세상의 힘(중력, 마찰력, 부력, 탄성력 …)을 빌려
벽을 부수고, 조각을 모아 문으로 가져가야 한다.

지금은 **1단계**입니다. 문 앞의 홀과 두 구역(낙하의 절벽, 서리 평원)이 열려 있고, 나머지 네 구역과 보스전은 다음 단계에서 이어집니다.

## 실행

`index.html`을 브라우저로 열면 바로 시작합니다.

```sh
npm start        # 로컬 서버
npm run build    # dist/nudge.html — 파일 하나짜리 배포본
npm test         # 엔진 정확도 + 장치 + 마우스 조작만으로 두 구역을 끝까지 푸는 시뮬레이션
```

## 조작

| | |
|---|---|
| 움직이기 | 마우스를 움직이면 포인터가 그대로 따라 움직입니다. 지연은 없고, 벽과 물체에 막힐 뿐입니다 |
| 밀기 | 물체에 대고 밀면 최대 40 N으로 밉니다. 포인터 옆에 그 순간의 힘이 N으로 표시됩니다 |
| 잡기 · 던지기 | 왼쪽 버튼을 누르고 있으면 가까운 물체에 줄이 걸립니다(최대 60 N). 휘두르다 놓으면 던집니다 |
| 일시정지 | `Esc` — 계속하기, 구역 처음부터, 소리, 새로 하기 |
| 구역 처음부터 | `R`을 2초 안에 두 번. 찾은 조각은 그대로 남습니다 |
| 소리 | `M` |
| 터치 | 손가락으로 끌어 움직이고, 오른쪽 아래 **잡기** 버튼을 누르고 있으면 잡습니다 |

시작할 때 마우스를 화면에 잠급니다(pointer lock). 잠글 수 없는 환경에서는 포인터가 마우스 위치로 가고, 화면 가장자리로 가면 시야가 따라갑니다.
찾은 조각과 부활 지점은 이 브라우저에 저장됩니다.

## 세계

```
            [빅 브라더 — 봉인]
낙하의 절벽 ←  태초의 문(조각 소켓 6개)  → 서리 평원
            [잠긴 바다] [지하세계] [탄성 공방] — 봉인
```

모든 공격은 힘입니다. 몬스터나 물체가 포인터를 치면 **작용점**에 화살표가 꽂히고 크기가 N으로 적힙니다. 60 N 이상이면 포인터가 부서지고, 마지막 부활 지점에서 다시 시작합니다.

## 설계 메모 (스포일러)

<details>
<summary>낙하의 절벽 — 중력과 무게</summary>

- **칼날 진자**: 30 kg 칼날이 복도를 쓸고 지나갑니다. 끝이 바닥에서 10 cm 위를 지나므로 밑으로 빠져나갈 틈은 칼날이 옆으로 높이 올라간 순간뿐입니다.
- **평형 승강판**: 발판 2 kg + 화강암 공 25 kg = 27 kg, 평형추 26 kg. 알짜힘 9.8 N이라 60 N 줄로 끌어올릴 수 있습니다. 빈 발판은 24 kg 차이로 튀어 올라가므로 아래에서는 핀이, 위에서는 걸쇠가 붙잡습니다. 빈 채로 위에 2초 있으면 스스로 내려와 다시 잠깁니다.
- **갈릴레이 판자**: 판자 위 두 컵에 무거운 것과 가벼운 것을 올리고 핀을 뽑으면 7 m를 함께 떨어집니다. 아래 두 판에 0.06 s 안에 함께 닿아야 깔때기 뚜껑이 열립니다. 깃털 뭉치는 공기 저항 때문에 늦게 떨어지는 미끼입니다.
- **드로퍼와 중력 구**: 드로퍼는 절벽 하늘 어디든 포인터를 따라다니며, 가만히 있는 포인터 위에서 20 kg 돌을 떨어뜨립니다. 바구니 밖에 멈춰 있는 돌은 4초 뒤 부서져 사라집니다. 중력 구(a = 40/r²)가 떨어지는 돌을 휘게 하므로 깔때기 입구 바로 위가 아니라 조금 비켜서 유인해야 합니다.
- **벽**: 600 N을 2초 버티면 무너집니다. 바구니(3 kg)에 돌 세 개(60 kg)가 들어가면 줄 장력이 617 N입니다.

</details>

<details>
<summary>서리 평원 — 마찰력 f = μN</summary>

- **고드름 홀**: 고무 블록 세 개(4 kg, 39 N)는 60 N 줄로 들어 나를 수 있습니다. 고드름은 떨어지기 전에 떨리고, 맞으면 82 N으로 부서집니다.
- **모래와 스케이터**: 모래 위 모래주머니(12 kg)는 0.85 × 118 N = 100 N으로 붙어 있어 포인터가 못 밉니다. 스케이터의 징 박힌 신발은 땅의 μ만큼 버팁니다(모래 0.9 × 392 N = 353 N, 얼음에서는 12 N). 높이 떠서 유인하면 모래주머니를 얼음으로 밀어내 주고, 같은 높이에 있으면 전속력으로 들이받습니다.
- **얼음 경사로**: 16.7°. 12.9 kg 이하만 40 N으로 밀어 올릴 수 있습니다.
- **클러치 기둥**: 바닥 없는 기둥이 움직이는 벨트 위에 서 있고, 벨트는 맨 아래 짐만 μk·N으로 끕니다(N은 기둥 전체 무게). 쌓는 순서가 μ를 정합니다. 90 kg을 다 넣었을 때 고무가 바닥이면 750 N, 모래주머니가 바닥이면 661 N, 강철이 바닥이면 353 N. 벽은 720 N을 2초 버텨야 무너집니다.
- **강철 블록**: 30 kg짜리가 절벽 끝에 놓여 있어서, 처음 밀고 온 짐이 이것부터 기둥에 떨어뜨립니다. 먼저 고무를 손으로 넣어 두어야 합니다.

</details>

## 구조

```
src/core       math, geometry
src/physics    body, collide(SAT, 이음매 무시), contact(정지·운동 마찰), joints(로프·슬라이더·회전), world
src/nudge      kit(재료·벽·판·핀·문) · pointer(마우스 = 포인터, 40 N / 60 N, 부서짐)
               monsters(드로퍼, 중력 구, 칼날 진자, 스케이터, 고드름) · game(구역, 부활 지점, 조각, 저장)
               regions/hub · regions/gravity · regions/friction
               view(파스텔 렌더러, 카메라, N 표시, 공격 화살표) · hud(소켓, 구역 이름, 오프닝 컷신)
               input(pointer lock · 절대 좌표 · 터치) · audio · main
tests          physics.test.js · nudge.test.js(포인터, 장치, 두 구역 전체 풀이)
tools/build.js 파일 하나짜리 배포본
```
